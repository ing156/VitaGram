# MAPPING_RU — карта ассетов для агента

Задача: подменить **только декоративную часть** уже реализованного UI VitaGram. Все размеры в физических пикселях Vita (960×544).

## Отступы для 9-slice

**Точный авторитетный источник — `manifest.json > nine_slice`**. Для ориентира:

- Стандартные панели, строки и вкладки: отступы `12, 12, 12, 12`.
- Меню/диалог: `20, 20, 20, 20`; размер источника 64×64.
- Капсула даты: `14, 10, 14, 10`.
- Прогресс-бар: `8, 5, 8, 5`.
- Скроллбар: `5, 8, 5, 8`.

Порядок: `left, top, right, bottom`. Контент не впечатывается в растягиваемую текстуру.

## Изменение тем

1. Не загружать все индивидуальные значки и их атлас одновременно без необходимости.
2. Для UI объектов использовать соответствующие ресурсы `themes/dark/…` / `themes/light/…`.
3. При переключении не изменять текущие данные и выбранные пункты.
4. Освобождать неиспользуемые текстуры после завершения текущего кадра/использования.

## Рендеринг

- `vita2d_draw_texture_part_scale()` принимает **коэффициенты** `dst_width/src_width`, `dst_height/src_height`, а не абсолютные размеры назначения.
- 9-slice — 9 blit-операций, а не один draw call.
- Для фонов/шапок достаточно 1 blit на объект.
- Не использовать `vita2d_set_clip_rectangle()` как маску скругления: он прямоугольный.
- Существующие аватары, миниатюры, сообщения, даты, имена и заголовки рисовать по текущей модели данных.
- Экран видеоплеера: заменить рамку, индикатор прогресса и контекстное меню; кадр рисовать исходным декодером.
