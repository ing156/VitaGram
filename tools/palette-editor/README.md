# VitaGram Palette Studio

Мастер дизайна VitaGram работает целиком в браузере. Публикация запланирована
по адресу **[ing156.github.io/VitaGram](https://ing156.github.io/VitaGram/)**;
адрес заработает после включения GitHub Pages и первого успешного deployment.

1. Откройте веб-мастер и выберите готовую палитру либо загрузите свой JSON.
2. Настройте цвета и проверьте нужные экраны предпросмотра.
3. Нажмите **Сохранить тему** — JSON скачается на ваше устройство.
4. Скопируйте JSON в **`ux0:data/vitagram/palletes/`** на PS Vita. Можно сразу
   установить набор: распакуйте все файлы тем в эту папку.
5. Перезапустите VitaGram и выберите тему по имени файла в настройках.

Набор — это несколько самостоятельных файлов тем, например:

```text
ux0:data/vitagram/palletes/
├── black-blue.json
├── black-red.json
└── my-light.json
```

Файлы должны лежать непосредственно в `palletes`, без дополнительной папки
набора. ZIP сначала распакуйте. Каждая тема появится отдельным пунктом после
перезапуска; загружаются до 64 корректных файлов, каждый не больше 8 КиБ.
Один большой каталог с полями `brand`/`colors` не является набором готовых
тем: сначала создайте из него палитры с цветовыми ролями приложения.

Учётная запись GitHub пользователю не нужна. Палитры обрабатываются локально
в браузере; мастер не отправляет их в репозиторий и не применяет на Vita
автоматически. Для переноса файла используйте привычный способ, например VitaShell.
Перед закрытием страницы сохраните JSON: автоматического сохранения черновика нет.

Для работы без интернета скачайте **VitaGram-Palette-Studio.html** из релиза
или сохраните [автономную копию с сайта](https://ing156.github.io/VitaGram/VitaGram-Palette-Studio.html).
Откройте файл в современном браузере Windows/Linux. Интернет, сервер и Python
для работы скачанного редактора не нужны.

В редакторе доступны готовые паттерны, каталоги красок, поиск по имени,
коду и HEX, выбор основных и дополнительных цветов. При включённых автооттенках
пять основных цветов формируют шапку, выделение, обводки и поверхности.
Предпросмотр показывает девять экранов: список чатов, историю сообщений,
настройки, выбор темы, меню чатов, вложения, поиск, опрос с RadioButton и радиальное меню. Координаты, размеры
и шаги строк берутся из общего с приложением `src/ui_layout.h`.
Используются настоящие маски, Noto Sans и русские строки VitaGram,
включая значки кнопок и шесть состояний батареи. Содержимое — демонстрационное;
сглаживание текста браузера может отличаться от PS Vita.
Для радиального меню размеры берутся из `src/radial_menu.h`: диаметр 496 px,
центр 216 px, зазоры и скругления совпадают с приложением. Выбирайте лепесток
кликом или списком «Действие»; обе кнопки L/R переключают «Новое / Ответ».
Изменение палитры сразу обновляет стекло, свечение, подписи и пиктограммы.
В тёмных темах блики ограничены относительно поверхности; текст подбирается
по контрасту, цвет внутри акцентных значков — чёрный или белый. Центральная
подложка имеет непрозрачность не ниже 245/255, лепестки — 217/255 до градиента.
Это статический вид открытого меню. Canvas сглаживает кривые браузером;
анимация и покрытие пикселей на Vita могут отличаться.

В истории второе сообщение отвечает на первое: внутри показана цитата с
именем автора, текстом исходного сообщения и акцентной полосой. Подложка
использует роль `date`, автор и полоса — `accent`, текст — `text`, как в
VitaGram. Высота карточки и положение следующих сообщений учитывают цитату
и выбранный размер шрифта.

Как в приложении, в списке чатов пять вкладок и девять компактных строк:
без добавленных превью сообщений и времени. Шапка — 36 px, статус — 23 px,
поиск — 26 px; начало списка с папками — y=151, шаг — 43 px.
Параметры предпросмотра позволяют выставить шрифт 70–130%, прозрачность
поверхностей 20–100% и форму аватаров, как на вашей Vita. По умолчанию —
120%, 75%, скруглённые аватары. Эти параметры не меняют JSON темы.
При достаточной ширине экрана canvas показывается в размере 960×544 без увеличения.

1. Выберите паттерн или откройте JSON через **Открыть JSON**.
2. Выберите цветовую роль и измените цвет системным диалогом, HEX или каталогом.
3. Дайте теме имя. Под ним показан размер имени в байтах UTF-8.
4. Нажмите **Сохранить тему**. Браузер скачает `<имя>.json`.
5. Скопируйте файл на Vita в **`ux0:data/vitagram/palletes/`**.
6. Установите VitaGram 0.37.94+, перезапустите его и выберите тему в настройках.

Каталог на Vita называется именно `palletes`. JSON не отправляется в интернет;
редактор только читает выбранные вами файлы и сохраняет результат загрузкой.
Несохранённые изменения защищены предупреждением при закрытии/смене паттерна.
Предупреждения о контрасте не запрещают экспорт собственного оформления.
Оттенки батареи вычисляются так же, как в VitaGram 0.37.88+.

**Обычная рамка** (`border`) и **Рамка выделения** (`focus`) находятся
в едином списке цветовых ролей сразу после акцента. Выберите нужную роль
и измените цвет общим диалогом, HEX или каталогом. Настройки сразу видны
в предпросмотре и записываются в JSON.
После ручной настройки автооттенки сохраняют выбранные цвета рамок даже
при изменении основных цветов и выключении/включении автоподбора.
Импортированные рамки также сохраняются при последующем редактировании.
Выбор другого готового паттерна возвращает рамки этого паттерна.
Роль `focus` также окрашивает подсветку фокуса и связанные с ней волны.
С новыми цветами индикаторов и иконок экспорт требует VitaGram 0.37.94+;
файл переносится в `palletes` как прежде. Старые JSON работают в новой версии.

В общем списке доступны независимые роли: **Иконки интерфейса** (`icon`),
**Непрочитанные / свечение** (`notification`), **RadioButton · выбран**
(`control_active`), **RadioButton · не выбран** (`control_inactive`),
**Отметки доставки** (`delivery`). Иконки не меняют цвет текста; цвет точки
непрочитанного применяется и к её ореолу. Для проверки RadioButton выберите
экран **Опрос**, отметки доставки видны в истории. Цветные кнопки контроллера,
батарея и предупреждающие значки сохраняют свои отдельные роли.
У старых JSON иконки наследуют `text`, RadioButton — `accent`/`muted`,
отметки доставки — `green`; индикатор непрочитанного по умолчанию синий.

JSON должен быть объектом известных цветовых ролей с HEX `#RRGGBB`, не больше
8 КиБ, без повторяющихся ключей. Обязательны `background`, `surface`, `text`,
`muted`, `accent`; остальные роли наследуются от стандартной светлой/тёмной
темы. Редактор экспортирует все редактируемые роли. `battery_low`,
`battery_warning`, `battery_charging` вычисляются из сигнальных цветов.

Имя файла без расширения — название темы. Допускается до 96 байт UTF-8
(например, 96 латинских или 48 обычных русских букв). Нельзя использовать
служебные символы путей, крайние пробелы/точки и системные имена Windows.
В интерфейсе VitaGram подпись ограничена шириной строки, имя файла не меняется.
VitaGram загружает первые 64 корректные темы по имени файла; каталог сканируется
один раз при запуске. Переименование создаёт другую тему. Если выбранный файл
удалён/некорректен, при следующем запуске используется стандартная Тёмная.
Выбор сохраняется по имени файла, поэтому добавление других тем его не сбивает.
Палитры открытые и не шифруются вместе с данными аккаунта.

Для сборки одного HTML из исходников нужен только Python 3:

```bash
python3 scripts/build-palette-editor.py
node tests/palette_editor_test.js
```

Результат: `build-modern/palette-editor/VitaGram Palette Editor.html`.
В HTML встраиваются только явно перечисленные данные: Open Color (132 цвета, MIT),
Little Greene и шесть паттернов (Светлая, Тёмная, два Little Greene, black-blue,
black-red). Предпросмотр списка тем включает также VHBB — всего семь тем приложения.
Добавление постороннего JSON в `assets/` не публикует его автоматически.
Текст лицензии Open Color включён в HTML. Никаких CDN и внешних шрифтов нет.

Проверка интерфейса в Chromium (Playwright нужен только разработчику):

```bash
npm install --prefix /tmp/vitagram-editor-test playwright
PLAYWRIGHT_BROWSERS_PATH=/tmp/vitagram-editor-browsers /tmp/vitagram-editor-test/node_modules/.bin/playwright install chromium
PLAYWRIGHT_BROWSERS_PATH=/tmp/vitagram-editor-browsers node tests/palette_editor_browser_test.js
```

Путь к модулю Playwright можно задать через `PLAYWRIGHT_MODULE`, а папку
снимков экрана и тестовых экспортов — через `EDITOR_TEST_OUTPUT`.

## Публикация на GitHub Pages

В репозитории подготовлен workflow
[Palette Studio Pages](../../.github/workflows/palette-studio-pages.yml).
Он собирает мастер в один `index.html`, проверяет палитры и автономный HTML,
после чего публикует только содержимое `build-modern/palette-site`.
Исходники, локальная конфигурация и файлы `release` на сайт не копируются.
Pull request запускает сборку и проверки, но не публикацию.

1. Добавьте исходники мастера, маски, палитры, доступные каталоги, тестовые
   фикстуры и workflow в коммит. Локальные неотслеживаемые файлы не появятся в CI.
2. В репозитории **Settings → Pages → Build and deployment → Source**
   выберите **GitHub Actions**.
3. Отправьте изменения в `master` либо запустите **Actions → Palette Studio Pages → Run workflow**.
4. После успешного deployment откройте адрес, показанный в environment `github-pages`.
   Для `ing156/VitaGram` ожидаемый адрес — `https://ing156.github.io/VitaGram/`.

Все шрифты, маски, лицензии и два встроенных каталога включены в HTML.
Добавьте в коммит `assets/open-color.json`, `assets/OpenColor-LICENSE.txt`
и `assets/little-greene.json`. Локальный архив `local-palettes/` исключён из Git
и не используется сборщиком.

Локальная проверка тех же файлов, которые публикует workflow:

```bash
python3 scripts/build-palette-editor.py build-modern/palette-site/index.html
node tests/palette_editor_test.js build-modern/palette-site/index.html
cp build-modern/palette-site/index.html build-modern/palette-site/VitaGram-Palette-Studio.html
python3 -m http.server 8000 --directory build-modern/palette-site
```

Откройте `http://localhost:8000/`. Для выпуска автономного HTML приложите
`VitaGram-Palette-Studio.html` к релизу как отдельный файл; версия приложения
при публикации страницы не изменяется.

## Загрузка собственного каталога

Нажмите «Открыть каталог JSON» и выберите JSON, например `assets/little-greene.json`
или [минимальный пример](examples/catalog.json):

```json
{"brand":"Мой каталог","license":"Собственные цвета","colors":[
  {"code":"01","name":"Синий","hex":"#102030"}
]}
```

Обязательны массив `colors` и `hex` в формате `#RRGGBB` у каждого цвета.
Поля `code`, `name`, `brand`, `source`, `note`, `license` необязательны.
Размер файла — до 2 МиБ, число цветов — от 1 до 10 000; максимум 16 каталогов
в сессии вместе со встроенными. Повторная загрузка файла с тем же именем
заменяет ранее импортированный каталог. Повреждённый файл не меняет библиотеку
или тему. Выберите цветовую роль, найдите оттенок и нажмите его образец.

Файл читается локально, без отправки на сервер; перезагрузка страницы удаляет
импортированные каталоги. Экспорт темы содержит только цветовые роли,
без полного справочника и его метаданных. На Vita устанавливаются именно темы
в `ux0:data/vitagram/palletes/`, а не исходные каталоги.

## Права на каталоги

Open Color распространяется по MIT с сохранением уведомления об авторстве
и текста лицензии. Little Greene оставлен в мастере и приложении по просьбе
пользователя. Темы Little Greene — использованы материалы @ElvisSuperStar007.
Другие брендовые каталоги
и основанные на них предустановки исключены из текущих сборок.
